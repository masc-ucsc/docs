    Pyrope Standard Library¶

    TBD

    The standard library is not implemented yet; this chapter is the wish-list for it. See Implementation status.

    This is a list of functionality that import("prp") should produce.

    Basic operations¶

    All the LNAST node have an associated function matching name to simplify the creation of operations: plus, minus, mult, div, mod, ror...

    const prp = import("prp")
cassert(prp.plus(1,2,3) == 6)

    Library code: 

    comb plus(...a:signed) -> (r:signed) {
  r = 0
  for e in a {
    r += e
  }
}

    Array/Tuple operators¶

    Size of length¶

    Sample use: 

    const x = (1,2,23)

cassert(prp.len(x) == 3)

    Library code: 

    comb len(x) -> (r) { r = x.[size] }

    map¶

    Sample use:

    const x = (1,2,3)
comb inc(a) -> (r) { r = a + 1 }

cassert(x.map(inc) == (2,3,4))

    Library code: 

    comb map<T>(f, ...x:[]T) -> (r:[]) {
  r = nil
  for e in x {
    r = (...r, f(e))
  }
}

    filter¶

    Sample use:

    comb not_two(a) -> (r) { r = a != 2 }

cassert((1,2,3).filter(not_two) == (1,3))

    Library code:

    comb filter<T>(f, ...x:[]T) -> (r:[]) {
  r = nil
  for e in x {
    if not f(e) {
      r = (...r, e)
    }
  }
}

    reduce¶

    Sample use:

    cassert((1,2,3).reduce(prp.plus) == 6)

    Library code:

    comb reduce<T>(op, ...x:[]T) -> (res:T) {
  if x.[size] <= 1 {
    res = x
    return
  }

  res = x[0]
  for i in x[1..] {
    res = op(res, i)
  }
}

    Strings¶

    String helpers follow the C++23 string_view naming where possible:

    const s = "hello"
cassert(s.len() == 5)
cassert(s.find("ll") == 2)
cassert(s.substr(1,3) == "ell")

    File I/O¶

    File access comes from a cpp import; there is no special grammar. It is debug-only simulation functionality (used inside test blocks), not synthesizable:

    type Fs = ( read_file: comb(path:string) -> (data:string) )
const fs:Fs = cpp("file_io")

test vectors.load {
  const cfg = fs.read_file("config.txt")
  puts(cfg)
}

    Data structures¶

    const q = prp.queue.make[signed](depth=16)
q.push(1)
assert(not q.empty())
const v = q.pop()

    Math and utilities¶

    assert(prp.math.gcd(12, 18) == 6)
const s = prp.str.join(("a","b"), ",")
